# دویچلب 🇩🇪 — DeutschLab

اپلیکیشن موبایل‌محور آموزش زبان آلمانی، به سبک دهکده زبان، با رابط فارسی.

## مرحله اول (همین نسخه)

- **کتاب‌ها:** Menschen ،Starten wir! و Momente — در سطوح A1 تا B2
  - هر کتاب جلد اختصاصی (عنوان، سطح، ناشر و ISBN در صورت موجود) و فهرست درس دارد تا کاربر دقیقاً بداند روی چه کتابی کلیک می‌کند
  - هر سطح: درس نمونه با موضوع آلمانی، توضیح فارسی و نکته گرامری
  - واژه‌های کلیدی هر سطح + تلفظ با صدای دستگاه
  - **خواننده کتاب:** در صفحه هر کتاب، کاربر می‌تواند PDF نسخه قانونی خودش را از روی گوشی انتخاب کند و همان‌جا بخواند؛ فایل آپلود یا ذخیره نمی‌شود
- **پادکست‌ها:** سطح‌بندی‌شده از A1 تا C1
  - Coffee Break German ،Slow German ،Easy German ،Auf Deutsch gesagt
  - و اخبار آهسته دویچه‌وله (DW)
- **داستان‌ها:** سطح‌بندی‌شده از A1 تا C1
  - متن آلمانی + ترجمه فارسی + واژه + سؤال فهم مطلب + خواندن با صدا
- **پیگیری پیشرفت:** تیک «انجام شد» برای درس، پادکست و داستان؛ ذخیره در مرورگر
- فیلتر سطح (A1 ،A2 ،B1 ،B2 ،C1) و جستجو در همه بخش‌ها

## اجرا (بدون نصب و بدون بیلد)

```bash
# روش ساده: فایل index.html را در مرورگر باز کن
# روش بهتر (پیشنهادی):
python3 -m http.server 8000
# بعد در مرورگر: http://localhost:8000
```

روی گوشی اندروید هم با همین روش کار می‌کند و با «Add to Home Screen»
مثل یک اپ نصب می‌شود (PWA، فایل `manifest.json` آماده است).

## ساخت نسخه اندروید واقعی (مرحله بعد)

این نسخه وبِ موبایل‌محور است تا منطق، محتوا و رابط کاربری زود دیده و
تست شود. برای خروجی APK/AAB با Capacitor:

```bash
npm install @capacitor/core @capacitor/cli
npx cap init "DeutschLab" com.deutschlab.app --web-dir=.
npx cap add android
npx cap open android
```

بعد در Android Studio خروجی APK گرفته می‌شود.

## نکته مهم درباره کپی‌رایت

متن و فایل صوتی رسمی کتاب‌های Menschen ،Starten wir! و Momente و
پادکست‌های نام‌برده **داخل این ریپو نیست**. چیزی که اینجا هست، مسیر
درسی، درس نمونه، خلاصه گرامری و واژه‌های پرکاربرد است که به‌صورت
مستقل برای آموزش نوشته شده. جلدهای نمایش‌داده‌شده هم طرح گرافیکی
داخل اپ با عنوان و مشخصات دقیق کتاب هستند، نه تصویر جلد چاپی ناشر.
برای خواندن متن کامل، کاربر نسخه قانونی خودش را با ISBN درج‌شده
از فروشگاه Hueber تهیه می‌کند و در خواننده داخل اپ باز می‌کند.
برای افزودن محتوای رسمی به خود اپ، باید مجوز ناشر گرفته شود.

## نقشه راه بعدی (با تأیید مصطفی)

- آزمون تعیین سطح و آزمون پایان هر درس
- فلش‌کارت با مرور فاصله‌دار
- بخش گرامر کامل، مکالمه و شنیداری
- افزودن فایل صوتی دارای مجوز برای کتاب‌ها و پادکست‌ها
- نسخه Flutter/Kotlin بومی اندروید، در صورت انتخاب

## ساختار

```
index.html        # پوسته اپ و ناوبری پایین (مثل اپ اندروید)
css/style.css     # تم تیره موبایل‌محور
js/data.js        # داده کتاب‌ها، پادکست‌ها و داستان‌ها
js/app.js         # منطق اپ: فیلتر، جستجو، پیشرفت، تلفظ
manifest.json     # نصب به‌صورت PWA
```
